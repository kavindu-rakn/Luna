Generated vs free CC0 recordings

Either way, nothing loads until a visitor turns sound on, so neither choice touches the Lighthouse score.

Generated in the browser

  • A few KB of code covers every sound on this page; nothing to download
  • Follows the data: pitch from illumination, a chime per exact phase, an ambient bed that brightens toward Full
  • Never repeats exactly, so it doesn't grate after the fiftieth click
  • One consistent character across every sound
  • Instant, sample-accurate timing for scrubbing
  • Synthesis has a ceiling: real textures (glass, paper, wood) are hard to fake
  • Takes tuning to avoid sounding "8-bit" or toy-like

Free CC0 recordings

  • Real, rich textures from day one (what 21hrs.space does)
  • CC0 needs no credit and allows any use. Good sources: Kenney's interface packs and Freesound filtered to CC0
  • Bytes: about 80 KB for eight short sounds, plus 300–700 KB for a 45–60 s ambient loop (compressed)
  • The same file every time; pitch-shifting helps a little
  • Can't follow the data without many variants
  • Mixed sources rarely share one character; each needs trimming, levelling and loop points
My recommendation

Generated for every interface sound, because Luna's sounds should follow the Moon: the chime at an exact phase, the tick that brightens toward Full. For the ambient bed, start generated too. If it doesn't feel rich enough once it's tuned, swap in one CC0 recording for the bed alone; that loop is the only place recordings clearly win.

For comparison, 21hrs.space plays four recorded files (image-effect.mp3, button-switch-on.wav, button-switch-off.wav, button-04.wav): 207 KB, all downloaded when the page opens. On iPhone, sound made through the Web Audio API follows the silent switch, which is the polite behaviour for interface sounds; recorded files played through it behave the same way.

These are first drafts to judge the approach, not final sound design. Everything here would be tuned again in the real build.
